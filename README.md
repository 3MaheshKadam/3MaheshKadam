### 🚀 Featured Project

**[Model Regression Detection System](https://github.com/3MaheshKadam/1-model-regression-detection-system)**

Tests LLM prompts the way you test code. A hand-curated golden dataset of 62 test cases, LLM-as-judge scoring against a committed baseline, and a GitHub Actions workflow that blocks pull requests when output quality drops. Fast (15-case) and full (62-case) evaluation modes, containerised with Docker.
